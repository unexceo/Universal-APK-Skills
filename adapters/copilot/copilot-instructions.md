# Universal APK Skills (loader)

For Android APK reverse engineering, modification, rebuild, signing, security analysis, game modding, or the commands
/engineeringapk, /analyzeapk, /apkscan, /apkdex, /manifestcheck, /apkresources, /modifyapk, /customizeapp, /changeappicon,
/changeapplogo, /changeappname, /rebuildapk, /apkbuild, /gameanalysis, /gamedebug, /gameassets, /gameui, /gameoptimization,
/apksafety, /securityaudit, /permissionaudit, /networkanalysis, /malwareanalysis, /apksign, /apkverify, /apkinstall,
/androidmanifest, /androiddebug, /androidproject, /androidoptimize, /helpapk:

1. Read `AGENTS.md` in the repository folder (commonly `universal-apk-skills/`), then `skills/<skill>/SKILL.md` for the command and follow its `### /<command>` section.
2. Only work on authorized APKs, never modify the original, never invent tool output, and refuse licensing/anti-cheat/credential/malware requests.
3. Without terminal access, give commands for the user to run and analyze pasted output.
